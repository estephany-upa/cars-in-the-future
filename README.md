# Cars in the Future

An animated, single-page concept site exploring how cars might look by 2050 and beyond.

Open `index.html` in any modern browser. No build step, no dependencies: plain HTML, CSS and JavaScript.

## What's inside

- **Hero** with a warp-speed starfield, synthwave road grid, speed lines and a hovering concept car that follows the cursor.
- **Timeline** of four eras (2030, 2040, 2050, 2070) with animated icons and a scroll-driven progress line.
- **Stats** that count up as they enter the viewport.
- **Anatomy** section where the car explodes into layers; hover the pulsing hotspots to inspect each system.
- **Design studio** to pick a body colour, drive mode (wheels, maglev, flight), ride height, canopy tint and lighting.
- **City** scene with a generated skyline, blinking windows and flying pods.

Respects `prefers-reduced-motion`.

## Files

| File | Purpose |
| --- | --- |
| `index.html` | Page structure and copy |
| `styles.css` | Theme, layout and all keyframe animations |
| `script.js` | Starfield, scroll reveals, studio controls and scene generation |

Everything on the site is speculative design fiction, not a description of real products.
